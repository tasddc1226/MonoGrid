MonoGrid

3개의 핵심 습관만 기록하는 미니멀 iOS 습관 트래커입니다. GitHub 잔디처럼 매일의 기록을 쌓고, 앱을 열지 않아도 빠르게 체크합니다.

App Store에서 보기 지원 받기
MG

습관을 더 많이 추가하지 않고, 더 오래 유지하게 돕습니다.

MonoGrid는 기록할 습관을 의도적으로 3개로 제한합니다. 중요한 습관만 남기고, 한 해의 진행 상황을 한눈에 확인합니다.

플랫폼 iOS
가격 무료
상태 출시됨
카테고리 Habit Tracker
Features

기록을 방해하지 않는 기능만 남겼습니다.

3개 습관 제한

너무 많은 목표를 만들지 않도록 핵심 습관 3개에만 집중합니다.

365일 그리드

GitHub 잔디처럼 하루하루의 기록이 시각적으로 쌓입니다.

빠른 기록

위젯, Siri, 제어센터를 통해 앱을 열지 않고도 기록할 수 있습니다.

iCloud 동기화

사용자의 개인 iCloud 계정을 통해 기기 간 데이터를 동기화합니다.

미니멀 통계

연속 기록, 달성률, 기간별 기록을 과하지 않게 보여줍니다.

모노랩스 원칙

회원가입 없이, 복잡한 소셜 기능 없이, 습관 기록에만 집중합니다.

Privacy

습관 데이터는 모노랩스 서버에 저장하지 않습니다.

MonoGrid의 습관 이름, 완료 기록, 설정 정보는 사용자의 기기와 개인 iCloud 계정에 저장됩니다.

개인정보 처리방침
Support

문제가 있거나 제안하고 싶은 점이 있다면 알려주세요.

동기화가 안 될 때

  • 동일한 Apple ID로 로그인되어 있는지 확인
  • iCloud에서 MonoGrid 사용이 활성화되어 있는지 확인
  • 네트워크 연결 후 앱을 다시 실행

위젯이 늦게 바뀔 때

iOS는 배터리 절약을 위해 위젯 업데이트 빈도를 제한할 수 있습니다. 위젯을 탭하거나 앱을 열면 최신 상태를 확인할 수 있습니다.
