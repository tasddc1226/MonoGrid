모노랩스 개인정보 처리방침

시행일: 2026년 7월 6일

1. 개요

모노랩스는 유용하고 심플한 웹/앱을 만드는 1인 제품 스튜디오입니다. 모노랩스는 개인정보를 필요한 만큼만 다루고, 제품별로 수집 범위를 최소화하는 것을 원칙으로 합니다.

2. 수집하는 정보

모노랩스 웹사이트는 회원가입을 제공하지 않으며, 방문자 개인을 직접 식별하기 위한 정보를 요구하지 않습니다.

개별 앱 또는 웹 도구는 기능 제공을 위해 다음과 같은 정보를 기기 또는 사용자의 개인 클라우드에 저장할 수 있습니다.

  • 사용자가 직접 입력한 콘텐츠와 설정
  • 앱 기능 제공을 위한 로컬 사용 기록
  • 문의 시 사용자가 직접 제공하는 이메일 주소와 문의 내용

3. MonoGrid 데이터 처리

MonoGrid는 습관 이름, 아이콘, 완료 기록, 설정 정보를 사용자의 기기와 개인 iCloud 계정에 저장합니다. 모노랩스 서버로 습관 데이터를 전송하거나 저장하지 않습니다.

4. MonoText 데이터 처리

MonoText에 입력한 텍스트는 글자수와 바이트 계산을 위해 현재 브라우저 안에서만 처리됩니다. 입력 내용은 모노랩스 서버로 전송되거나 저장되지 않습니다.

5. 제3자 제공

모노랩스는 사용자의 개인정보를 판매하지 않으며, 법령상 요구되는 경우를 제외하고 개인정보를 제3자에게 제공하지 않습니다.

6. 데이터 삭제

앱을 삭제하면 기기에 저장된 데이터가 삭제됩니다. iCloud에 동기화된 데이터는 사용자의 Apple ID iCloud 저장 공간 관리 화면에서 삭제할 수 있습니다.

7. 아동 개인정보

모노랩스는 13세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다.

8. 변경 사항

본 개인정보 처리방침은 제품 추가, 법령 변경, 운영 방식 변경에 따라 업데이트될 수 있습니다. 중요한 변경 사항은 본 페이지를 통해 안내합니다.
