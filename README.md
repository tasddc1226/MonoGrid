# 모노랩스 - 제품 허브

모노랩스의 제품 허브, 개인정보 처리방침, 지원 페이지를 배포하는 GitHub Pages 레포입니다.

- [허브 랜딩페이지](https://tasddc1226.github.io/MonoGrid/)
- [MonoGrid 제품 상세 페이지](https://tasddc1226.github.io/MonoGrid/products/monogrid.html)
- [개인정보처리방침](https://tasddc1226.github.io/MonoGrid/privacy-policy.html)
- [지원](https://tasddc1226.github.io/MonoGrid/support.html)

## 운영 메모

- 이 레포는 정적 페이지 전용입니다.
- iOS 앱 프로젝트는 [`MonoGrid-iOS`](https://github.com/tasddc1226/MonoGrid-iOS) 레포에서 관리합니다.
- 제품 목록은 `docs/products.json`에서 관리하고, 제품 상세 페이지는 `docs/products/` 아래에 둡니다.
- 추후 모노랩스 도메인을 구매하면 GitHub Pages의 custom domain으로 연결할 예정입니다.
